# Redistributable historical incident extracts

- **Iraq.** Derived from `IQ_SIGACTs.csv`, Harvard Dataverse file 7071257 in DOI 10.7910/DVN/JRYGFP. Dataverse labels the release [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The transformation standardizes selected columns and preserves a source-row reference. [Dataverse release](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/JRYGFP)
- **Yemen.** Derived from Yemen Data Project's Saudi-led air raids database, distributed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Source and credit go to Yemen Data Project. The transformation retains the requested 2015–2022 period, drops the undated row from the extract, and maps selected fields into the project schema. [Yemen Data Project](https://www.yemendataproject.org/data/)

The precise source files, URLs and checksums are in the [source inventory](../research/sources.csv). See the [data dictionary](../research/data-dictionary.md) for field mappings and the [research log](../research/research-log.md) for coverage limitations.
